CLUSTER WORKBENCH / 新同事上手

让集群上的 AI，连上你的通道。

准备自己的集群账号、校园网或学校 VPN。无需 GitHub 登录，无需先装 Node.js 或 Git。

完整解压，再安装

右键 ZIP →「全部解压」，放到固定目录，例如 C:\cluster-workbench。不要在压缩软件预览窗口内运行，也尽量避开下载文件夹和 OneDrive。

打开 install 文件夹，双击 install-workbench.cmd。安装器自动准备运行环境、创建桌面快捷方式并打开浏览器。首次需要联网下载约几十 MB 的 Node.js；本包不是离线安装包。

若看到系统来源提醒，先确认文件确实来自维护者并核对随包的 SHA-256，再按单位的软件安装要求处理。若安全软件报警，把提示交给维护者核实。

按页面引导接入集群

浏览器打开 http://127.0.0.1:8877。填集群用户名和密码，按提示核对主机指纹。专用密钥、个人端口、通道和集群代理配置会自动完成；密码不保存。

网页打不开时，检查本机代理让 127.0.0.1 直连。接不上集群时，先确认校园网/VPN和账号，再点页面里的「重试」。

选择 Claude / Codex 和登录方式

接入成功后，在同一页安装需要的工具，再选「官方账号登录」或「中转站地址 + Key」；官方 API Key 也可选择。工具和登录配置会写在你自己的集群账号下。

中转站填服务商给的 API 基础地址。集群的 http://127.0.0.1:个人端口 是出网代理，不是 API 地址；不用把这两个地址互相替换。公网中转站通过通道出网，校内地址会先测集群直连。

检查，再开始第一次对话

点「检查通道与工具」。按页面复制启动命令，粘贴到集群的新终端运行，再发送第一条消息。网络可达不代表 Key、额度与模型权限都有效；有认证错误时核对登录方式和服务商信息。

已有的 Claude/Codex 会话要退出重开。日常双击桌面「集群运维工作台」，把黑色运行窗口最小化即可；电脑断网、休眠或关闭工作台时，依赖这条通道的请求会中断。

出问题不用重装。

双击 install\diagnose-workbench.cmd，把桌面的 workbench-selfcheck.txt 和错误截图发给维护者。报告含本机路径与用户名，不包含密码、API Key 或私钥内容。不要发送自己的配置文件或密钥文件。

ZIP 版不能页面内自动更新。升级时先关闭旧工作台，解压新版到新目录，迁移旧目录的 config.local.json 和 work\runtime 后再安装、启动；这些文件可能含个人数据，只在自己的电脑之间保存和迁移。
